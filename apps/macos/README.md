# Local Services (macOS app)

A native SwiftUI front door for `lsd`: add a folder that has a `local-services.yaml`, and manage its
daemon-owned services from a menu-bar-friendly window instead of a terminal.

This app is another HTTP+SSE client of a per-folder daemon. It never talks to a managed process
directly.

```
 WorkspaceStore (~/Library/Application Support/LocalServicesApp/workspaces.json)
        │ one folder path per workspace
        ▼
 DaemonConnection.ensure(root:)  ──spawns──►  lsd --root <folder> manager ensure --json
        │ {instanceId, port, token, protocolVersion, runtimeDirectory, root}
        ▼
 ManagerClient  ──HTTP (Bearer token)──►  the folder's own daemon
```

`SidecarLocator.findLsdBinary()` finds a compiled `lsd`: bundled in the `.app`, installed under
`/Applications`, this checkout's `cargo build` output, then the login shell. See
`SidecarLocator.swift` for the full order.

## Requirements to build/run

- Xcode 15+ / Swift 5.10 toolchain (`swift build` works standalone).
- A Rust toolchain (`cargo`) to build `../../rust/bin/lsd` — `build-app.sh` does this for you;
  `swift run` also looks for `rust/target/{release,debug}/lsd` next to this checkout.

```bash
cd apps/macos
swift build     # or: swift run — a raw dev binary, resolves lsd from this checkout
```

## Packaging a local `.app`

```bash
task macos:install
```

Produces an ad-hoc-signed `Local Services.app` bundling compiled `lsd` at
`Contents/Resources/lsd/bin/lsd`. **This is local packaging, not distribution**: ad-hoc signing
(no Developer ID) means Gatekeeper still treats it as untrusted on any *other* machine. Set
`LSD_DEBUG=1` to log which `lsd` path resolved.

`AppIcon.icns` is generated by `scripts/generate-icon.sh` from `scripts/make-icon.swift`.

## What's implemented

- Add/remove workspaces (folders), persisted locally.
- Per-folder trust prompt before the first daemon connection.
- Connect (spawn-or-adopt the daemon via `lsd manager ensure`), list services with live status
  (polling `/v1/services` every 2s), start/stop/restart per service.
- Per-service log viewer.
- A workspace's live connection lives in `WorkspaceControllerRegistry` at the app level.
- `MenuBarExtra` — a global "ready/total" summary across every trusted workspace.
- Config watch: editing `local-services.yaml`/`.yml`/`.json` triggers `lsd manager reload`.
- "Start All" / "Stop All" in the toolbar and menu bar.

## Known limitations

- **No distributable `.app`** — still ad-hoc signed. Real distribution needs a Developer ID cert +
  notarization. A `bun build --compile` sidecar was tried and rejected (see AGENTS.md); the Rust
  binary does not hit that issue, which is why it can be bundled directly.
